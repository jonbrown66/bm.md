# 小红书图片分页容差设计

## 目标

减少小红书预览中图片仅轻微超出当前页时被整体移到下一页的情况，让每页尽量充分利用空间，同时保证图片不会被过度缩小或在导出时明显裁切。

## 范围

- 只调整小红书预览与对应导出的正文分页行为。
- 不改变封面、普通移动端/桌面端预览、文字与代码块的既有分页规则。
- 不增加新的用户设置或依赖。

## 分页策略

分页继续使用现有页面高度容差，避免测量舍入和图片加载后的轻微尺寸变化触发换页。

当当前页最后一个内容块包含图片，且它只因图片高度而轻微超出时：

1. 计算当前页剩余空间与图片需要缩小的比例。
2. 图片保持宽高比缩小，最低缩放比例为原显示尺寸的 85%。
3. 缩放后能够落在页面安全区域内，则保留在当前页。
4. 缩到 85% 后仍不能完整放入，则不继续压缩，沿用现有逻辑将整个内容块移到下一页。

图片之外的内容块，以及无法安全识别或调整的复合块，继续使用现有整块换页规则。

## 实现边界

- 分页阶段生成确定的图片尺寸约束，使预览与导出复用同一份分页 HTML。
- 不依赖允许真实内容溢出页面来“塞下”图片；容差只用于吸收测量误差。
- 保留图片原始宽高比，不裁切图片，不让图片低于 85% 的最低缩放比例。
- 避免修改编辑器中的原始 Markdown 或全局主题样式。

## 验收标准

- 图片轻微超出当前页时，能以不低于 85% 的比例缩小并完整留在本页。
- 需要缩小到 85% 以下才能放入时，图片整块进入下一页。
- 导出的分页数量和内容位置与小红书预览一致。
- 页面不存在可见的底部裁切或纵向滚动溢出。
- 现有文字、表格、代码块和结构分页行为不回退。

## 验证

- 为缩放比例判断与分页选择补充单元测试。
- 运行相关 Vitest、TypeScript 检查和 lint。
- 使用包含“轻微超出”和“明显超出”图片的示例进行浏览器预览检查，并核对导出页。

## 风险

- 图片加载完成前后的测量尺寸可能不同；分页计算必须继续等待图片就绪。
- 包含图片与复杂说明内容的复合块不应被盲目缩放，无法安全处理时应回退到整块换页。
